# Hackathon and sponsor disclosure

Official [PayPal AI Hackathon rules](https://paypalaihackathon.devpost.com/rules) were reviewed during this build. The published deadline is **November 12, 2026 at 12:00 PM PST**, corresponding to **November 13, 2026 at 1:30 AM IST**. Confirm the latest official rules before submission.

The rules require a functional build, public open-source repository, description and a publicly visible YouTube demonstration shorter than three minutes. A working local build with complete setup instructions is accepted instead of public hosting. Eligibility, original-work requirements and all team/submission declarations remain the entrant's responsibility.

## Implemented tooling

- PayPal Orders v2 sandbox server integration, hosted approval redirect, capture detail verification, webhook signature verification and Payments v2 refund integration are implemented. No live provider calls have been verified because sandbox merchant credentials and buyer approval were not available.
- AG Grid Community is actually loaded in Inventory vault with customized dark theming, sorting, filtering, pagination and inventory editing actions. The application uses no paid grid features.
- The [AG Grid sponsor page](https://paypalaihackathon.devpost.com/details/aggrid) emphasizes AG Studio, custom widgets and Studio Agent Framework, and advertises a 45-day trial. **AG Studio and Studio Agent Framework are not integrated**. No sponsor award eligibility is asserted from Community usage alone.
- The [APIMatic sponsor page](https://paypalaihackathon.devpost.com/details/apimatic) and its linked PayPal context-plugin resource were investigated. An APIMatic context tool was not connected in this environment; official PayPal documentation was used directly. **No APIMatic usage or prize eligibility is claimed.** No subscription, trial or paid account was activated.

The app provides bring-your-own-key adapters and optional Ollama, not a shared platform AI subscription. Sponsor affiliation is not implied by product names or installed packages.

## Remaining external actions

1. Configure your sandbox merchant and complete an actual buyer-approved capture; retain genuine transaction evidence.
2. Connect your own model or local Ollama and record actual model tool invocation.
3. Record/review the demo against the current verified state. A local two-minute recording is provided separately when created; it does not automatically become a YouTube submission.
4. Upload an honest final video publicly to YouTube using your authorized account.
5. Fill Devpost with the supplied text, actual repository URL and genuine video URL; review eligibility and submit.
6. Retain the actual Devpost receipt. No receipt is claimed or fabricated by this repository.
